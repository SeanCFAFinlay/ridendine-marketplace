## Part 3 — Claims deliberately **not** made

Stated so a reader knows where the map's edges are, rather than inferring completeness:

- **Not claimed:** that all 180 API routes are correctly authorised. The gate proves a guard string is present in state-changing routes; it does not prove ordering, resource-correctness, or anything about `GET`. Roughly 25 routes were read in full.
- **Not claimed:** that RLS policies are correct. They exist on all 112 tables and follow a consistent pattern. Their correctness is untested (U-08).
- **Not claimed:** that the pre-discount tax calculation is wrong. It is *implemented consistently*; whether it is *correct* is a legal and accounting determination outside this analysis.
- **Not claimed:** that the 24 routes flagged by the orphan heuristic are unreachable. Only the four payout sub-routes were confirmed by direct inspection; the rest are POSSIBLE.
- **Not claimed:** that Sentry produces zero events. It is claimed that no initialisation path exists in the source and no Sentry code appears in the build output. If Sentry is somehow receiving events, the mechanism is not in this repository.
- **Not claimed:** that Vercel Cron uses `GET`. That is external platform behaviour. **What is claimed from repository evidence is the mismatch itself**: the work is in `POST`, the local simulator uses `POST`, and `GET` is a status-only handler. U-01 settles it either way in one query.
