Primary Workflow

Checkout to payment to kitchen to dispatch to delivery to money, with every gate and failure branch. Amber = gate, red = failure, green = success.

    G1 -->|no| E1["307 → /auth/login"]

    C2 -.->|fail| CL

Startup Sequence

What happens on every request, in order. Middleware runs before anything else; the engine is built per request.

%% RIDENDINE — Startup / request initialisation sequence
sequenceDiagram
    autonumber
    participant B as Browser / caller
    participant MW as src/middleware.ts
    participant SB as Supabase Auth
    participant RT as Route handler
    participant EN as createCentralEngine
    participant DB as Supabase Postgres

    B->>MW: HTTPS request
